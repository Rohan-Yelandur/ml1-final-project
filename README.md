# Social Media Bot Detection

This project implements various machine learning algorithms to detect fake social media accounts among
real users.

# Datasets

- [fake_users.csv](https://www.kaggle.com/datasets/satishkumarprajapati/fake-social-media-account-detection-dataset?select=fake_users.csv)

- [real_users.csv](https://www.kaggle.com/datasets/satishkumarprajapati/fake-social-media-account-detection-dataset?select=fake_users.csv)
